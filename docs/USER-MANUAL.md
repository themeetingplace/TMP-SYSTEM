## 1. 系統概覽

**聚空間 PMS 是什麼？** 一站式房屋租賃管理系統，把「物件、租客、合約、帳款、維修」全部串在一起。PMS = Property Management System，租賃業常見命名。

**主要功能（左側選單由上到下）：**

| 分區 | 頁面 | 用途 |
|---|---|---|
| 總覽 | 首頁 | 看待辦事項、空床、最新狀況 |
| 營運 | 物件管理 | 看所有床位、空床、新增入住 |
| 營運 | 住房一覽 | 矩陣表看各館各床的繳款狀態 |
| 營運 | 合約管理 | 看 / 建立 / 退租 / 續約所有合約 |
| 帳務 | 帳務管理 | 看所有帳單、收支、待繳 |
| 營運 | 維修管理 | 處理租客回報的維修 |
| 營運 | 租客清單 | 看所有租客資料、LINE 綁定狀態 |
| 報表 | 各館收入報表 | 每月各館營運成績 |
| 系統 | 系統設定 | 館別管理、付款方式、雲端同步 |
| 系統 | 帳號管理 | (Owner 才看得到) 管理小編帳號 |

## 2. 登入 / 帳號管理

### 登入
1. 開 https://themeetingplace-bms.pages.dev
2. 點「**使用 Google 帳號登入**」
3. 選你的 Gmail（必須是白名單內的帳號）→ 同意授權
4. 跳回 → 看到首頁 = 登入成功

### 帳號設定
- 左下 sidebar 點頭像 / 名字 → 開「帳號設定」
- 可改：顯示名稱、頭像（16 個圖示 × 8 色塊組合）
- Email 不能改

### 新增 / 移除小編帳號（Owner 限定）
- 左側 sidebar → **系統 → 帳號管理**
- 點「**+ 新增管理員**」（這顆按鈕名稱是「新增管理員」但角色就是 admin / 小編）
- 填 email + 顯示名稱 + 角色（Owner / Admin / Viewer）
- 對方須先用 Google 登入過一次才會啟用

> **角色差別：**
> - 👑 **Owner**：完整權限，可管理其他帳號（老闆 + 你）
> - 🛠 **Admin**：完整 BMS 操作，但**不能**管理帳號（員工）
> - 👁 **Viewer**：預留給只能看的角色（目前等同 Admin）

## 3. 日常主要操作

### 3.1 新住客入住

> **適用場景**：有人來看房 → 確定要住 → 簽約 → 開始算錢

#### 方法 A：從「物件管理」進入（推薦）
1. 左側 sidebar → **營運 → 物件管理**
2. 右上角點 **「+ 新增入住」**
3. 跑 3 步 wizard：
   - **Step 1：床位 + 租客資料**
     - 選館別 → 選床位（會顯示哪些是空床）
     - 填租客：來源（FB / 591 / 朋友介紹...）、姓名、電話、Email、緊急聯絡人
     - 💡 輸入姓名 / 電話時會自動搜尋舊客資料 → 是舊客可一鍵載入
   - **Step 2：合約條件**
     - 入住日期（= 合約起始日）
     - 合約期：1 個月 / 3 個月
     - 月租金（會自動帶該床位的設定，可調）
   - **Step 3：收款記錄**
     - 加減項目（可多筆）— 例如：季繳優惠 -1000、能源費 +500
     - 應收總額 = 月租 × 期數 + 加項 - 折扣（系統自動算）
     - 已收金額：全收訖填全額 / 部分繳填部分 / 還沒收填 0
     - 付款方式：匯款 / 現金 / 信用卡 / LINE Pay...
4. 點「下一步：確認資料」
5. 確認頁仔細看 → 「✅ 確認建立」
6. 系統會一氣呵成做完：
   - 建立合約（自動生成編號 C0XX）
   - 自動產生帳單（已標記「應繳 / 已繳清」狀態）
   - 床位狀態改成「已出租」
   - 租客資料寫入 / 更新
   - 排程入住任務（給看房當天用）

#### 方法 B：從「住房一覽」（適合知道哪間空床的情境）
1. 左側 sidebar → **營運 → 住房一覽**
2. 點空床 → 該床位欄會有「+ 入住」按鈕
3. 點下去 → wizard 自動帶入該床位（跳過 Step 1 的選床步驟）

### 3.2 退房 / 終止合約

> **適用場景**：合約到期不續、提前退租、押金結算

#### 步驟
1. 左側 sidebar → **營運 → 合約管理**
2. 找到那筆合約（用搜尋或館別篩選）
3. 點該列的「**🚪 退租**」按鈕（或在 detail 內點退租）
4. 填寫：
   - **退房日期**（預設今天，可改）
   - **押金退還金額**（預設 = 押金全額；損壞扣項可減）
   - **備註**：扣款原因、轉介紹紀錄等
5. 「✅ 確認退租」
6. 系統會：
   - 合約狀態變「已終止」
   - 床位狀態變「待租 / 空床」
   - 自動產生「押金退還」帳單記錄
   - 5 秒內可按「復原」（按錯了的緊急救援）

#### 即將到期合約的「續約 / 退租 / 暫緩」決策
- 14 天內到期的合約會出現在**首頁待辦**「合約事項」
- 點待辦 → 直達該合約 detail
- 有三顆按鈕：
  - **🔁 續租**：建立新合約延續，承接同一床位 + 租客
  - **🚪 退租**：跑退房流程
  - **⏸ 暫緩**：告訴系統「我還沒決定，N 天後再提醒」

### 3.3 收支記錄

> **適用場景**：收到房租 / 付水電 / 對帳

#### A. 收房租（最常見）

**情境 1：建立入住時已經收清**
- 在 wizard 的 Step 3 已收金額填全額 → 帳單自動已繳清 → **不用再做任何事**

**情境 2：建立入住時還沒收 / 部分繳**
- 之後收到錢時：
1. 左側 sidebar → **帳務 → 帳務管理**
2. 找到那筆帳單（看「待繳」分頁或用搜尋）
3. 點該筆 → 編輯 → 改「已收金額」+ 付款方式 + 收款日
4. 存檔 → 狀態自動變「已繳清 / 部分繳款」

**情境 3：租客透過 LINE 回報帳號末 5 碼**
1. 租客在 LINE OA 傳「12345」（5 位數字）
2. 系統自動把這個末 5 碼附到他最近的未繳帳單上
3. 小編收到通知（如果有開）
4. 小編核對銀行對帳單 → 確認真的有入帳 → 帳務管理 → 把該筆帳單改「已繳清」

#### B. 記支出（水電、管理費、維修費...）

1. 左側 sidebar → **帳務 → 帳務管理**
2. 右上角點 **「+ 新增支出」**（或「+ 新增收入」如果是雜項收入）
3. 填：
   - 館別（可選「全館共用」）
   - 類別（水費 / 電費 / 管理費 / 房東租金 / 維修費...）
   - 金額
   - 到期日 / 入帳日
   - 備註
4. 存檔

#### C. 看「合約收款」的加減項目（季繳折扣、能源費等）

- 入住 wizard 的 Step 3「收款記錄」可加多筆 sub / add 項目
- 顯示在合約 detail 的「收款明細」區
- 報表會自動把這些算進淨收入

---

### 3.4 維修管理

> **適用場景**：租客報修、自己發現需要修、追蹤施工狀態

#### A. 租客 LINE 報修（自動）
- 租客在 LINE 傳「**維修：冷氣不冷會滴水**」
- 系統自動建立維修單，回覆「✅ 已收到維修申報 (M0XX)」
- 小編在 BMS 看到新增的維修單

#### B. 小編手動建立（房東/小編自己發現）
1. 左側 sidebar → **營運 → 維修管理**
2. 右上角「**+ 新增報修**」
3. 填：物件、問題描述、申報人、申報日期
4. 存檔

#### C. 處理流程
- **待處理** → 點「開始處理」→ 變「處理中」
- **處理中** → 點「完成」→ 填維修費用 → 變「已完成」
- 維修費會自動記到那館的支出

---

### 3.5 看房預約處理

> **適用場景**：LINE 有人說想看房

#### 流程
1. 對方在 LINE 傳「預約看房」/「入住詢問」/「想看房」之類關鍵字 → 系統自動回覆**入住詢問填空表**（要對方填姓名、電話、想看房時段、想入住館別...）
2. 對方填好回傳
3. 小編在 LINE 跟對方喬時段
4. 確定看房時間 → 在 BMS 處理：
   - **方案 A（推薦）**：直接走 §3.1 的入住流程，wizard Step 1 自動帶該對方為新租客
   - **方案 B**：先建一筆預約紀錄（如果你有用「預約看房」工單，但目前系統沒這個獨立模組，等簽約直接走入住流程）

## 4. LINE 官方帳號

聚空間官方 LINE 是「半自動 + 人工」的客服系統。系統會自動回應某些關鍵字，其他訊息小編自己看著回。

### 4.1 自動回覆對應表

| 觸發方式 | 系統回覆 |
|---|---|
| 加好友 | 「嗨 OOO！歡迎來到 聚空間✨ 請問有什麼可以協助您的？」+ 3 個按鈕（入住詢問 / 住客登記 / 找小編） |
| 訊息含「**入住** / 詢問 / **預約** / **看房** / 參觀 / 空房 / 租房 / 價錢 / 價格 / 租金 / 床位**」 | 入住詢問填空表（要對方填姓名電話想看時段...） |
| 訊息含「**小編** / 管理員 / 找人 / 聯絡 / 客服**」 | 「💬 小編會盡快回覆您...」（24 小時內同一人只回一次） |
| 訊息含「**綁定** / 我是房客 / 我是租客 / 帳號 / 登記**」 | 「請填寫住客資料表單完成登記」+ LIFF 登記表單連結 |
| 訊息是純 5 位數字（如「12345」） | 自動找該租客最近的未繳帳單，把這 5 位數標記為轉帳末 5 碼 |
| 訊息含「**維修：xxx**」 | 自動建立維修申報，回「✅ 已收到維修申報 (M0XX)」 |
| 訊息含「**帳單** / 帳款 / 明細**」（已綁定的租客） | 列出該租客的最近帳單狀態 |
| 直接輸入手機（10 碼開頭 09） | 嘗試自動綁定到該手機的租客資料 |
| **已綁定的租客**傳其他文字 | **保持沉默**（讓小編自然聊天，不要被機器人洗版） |
| **未綁定**訪客傳其他文字 | 「收到您的訊息！小編會回覆」+ 3 顆按鈕 |

### 4.2 主選單按鈕（quick reply）

每次系統回覆後底下會跳 3 顆按鈕：
- 🏠 **入住詢問** → 觸發入住詢問填空表
- 🔗 **住客登記** → 開啟 LIFF 表單（已是房客可登記資料 + LINE 綁定）
- 💬 **找小編** → 提醒「小編會盡快回覆」

### 4.3 重要設定（小編要知道）

**24 小時 cooldown**：「找小編」這類自動回覆設計成 24 小時內同一個 LINE 帳號只回一次，**避免你在跟客人聊天時被機器人插話**。

**已綁定房客的靜默原則**：當房客已綁定 LINE，傳的訊息**不是**末 5 碼 / 維修 / 帳單 / 找小編這類關鍵字時，系統會保持沉默，留給小編自然聊天。「找小編」是例外（強意圖）→ 不分綁定狀態都會回覆。

**LIFF 登記表單**：https://themeetingplace-bms.pages.dev/liff/ — 對方點「住客登記」會開這個表單，填完自動建立租客資料 + 綁定 LINE。

## 5. 進階功能

### 5.1 各館收入報表

- 左側 sidebar → **報表 → 各館收入報表**
- 每館顯示：出租率、月收入、月支出、淨利、毛利率
- 還有 6 個月 sparkline 趨勢圖
- MoM（比上月）/ YoY（比去年同月）變化
- 預期 vs 實收（空床損失）
- 可匯出 PDF 給房東看

### 5.2 系統設定

- **館別管理**：新增 / 編輯館別。改館別預設地址會問你「要不要同步到該館所有床位？」
- **房型 / 床位**：在各館下面新增房間、床位、設定月租
- **帳單類型**：預設有水費、電費、管理費等，可自訂
- **顧客來源**：FB、591、Google、朋友介紹...
- **付款方式**：匯款、現金、LINE Pay、信用卡...
- **合約範本**：上傳 PDF 範本，建合約時自動產出簽署檔
- **雲端同步**：可看同步狀態、手動觸發 pull / push

### 5.3 全域搜尋

- topbar 中間的搜尋框（或按 **`/`** 快捷鍵聚焦）
- 可搜：合約編號、租客姓名、物件名、館別
- 結果可直接點 → 跳到該物件 detail

### 5.4 首頁待辦

- 三張卡：合約事項 / 帳款事項 / 維修事項
- 每張卡列出該分類待辦項目
- 點任何一筆 → 直接跳到該物件 detail 處理
- 全部結清 → 顯示鼓勵性空狀態（「本月合約都安全 ✓」）

## 6. 常見問題

### Q1：登入跳「無權限存取」？
- 你的 Google email 不在白名單。請 owner 進「帳號管理」加你
- 確認 email 完全一樣（大小寫無關）

### Q2：手機開 BMS 看起來怪怪的？
- 已支援手機版：sidebar 變漢堡選單（左上）、表格自動轉卡片、modal 變 bottom sheet
- 確認用最新版瀏覽器
- 不要鎖在桌面版檢視

### Q3：改了館別資料但合約沒同步？
- 編輯館別「預設地址」時會跳確認 modal「要同步到該館 N 個床位嗎？」
- 沒按「套用」就只改館別本身、床位不會跟著動
- 補救：再編輯一次館別、改一下地址、跳出來時按「套用到所有床位」

### Q4：LINE 沒收到通知？
- 確認 ADMIN_LINE_USER_IDS 環境變數有設你的 LINE userId（可傳「/myid」到 OA 取得）
- Webhook 是否正常運作（Supabase Edge Functions → line-webhook 看 logs）

### Q5：刪錯東西怎麼辦？
- 大多數刪除動作會跳「5 秒倒數復原」toast — 點「復原」即可救回
- 過了 5 秒就真的進雲端被刪了
- **押金 / 已收款 / 合約結算金額** 這類重要欄位刪錯只能去 Supabase Dashboard 從 DB 救（聯絡開發者）

### Q6：合約建錯人 / 床位 / 期間？
- 在合約管理找到該合約 → 點「✏ 編輯」
- 改完存檔 → 系統會自動更新關聯的帳單（金額 / 期數變了帳單金額會跟著變）
- 但已收款 / 已繳清狀態**不會自動回滾**，要自己手動調整

### Q7：帳單明明已收，狀態還是「待繳」？
- 帳務管理 → 找到那筆 → 點 ✏ 編輯 → 填「已收金額」+ 「付款方式」 + 「收款日」→ 存
- 「已收金額 ≥ 應收金額」狀態自動變「已繳清」

### Q8：BMS 怎麼備份 / 還原？
- 雲端 = Supabase（資料庫即時備份）
- 本機 localStorage 是 cache，斷網時也能查
- 想完整備份：左側 sidebar → 系統設定 → **雲端同步** → 看「上次同步」時間
- 緊急救援：聯絡開發者從 Supabase 還原

### Q9：LINE 罐頭訊息「找小編」沒觸發？
- 24 小時內同一個帳號只會回一次（cooldown 設計，避免你跟客人聊天被插話）
- 想測試：等 24 小時 / 或用不同 LINE 帳號 / 或開發者去 Edge Function logs 查

### Q10：怎麼新增小編？
- 你必須是 Owner 才看得到「帳號管理」
- 進去 → 「+ 新增管理員」→ 填對方 email + 顯示名稱 + 角色（一般選 Admin）
- 對方收到通知（沒有自動 email，你要自己跟對方說：請去 BMS 登入 Google）
- 對方第一次登入用 Google 才會啟用
